Settings

Both tests auto-select their own server — nothing to configure there. Just set how often they run below.

Local — Cloudflare Speedtest

Uses Cloudflare's public speed test endpoints — the same ones behind speed.cloudflare.com. Cloudflare's network is anycast, so this hostname always automatically routes to whichever of their edge locations is nearest/fastest — no server selection needed, and no separate binary to download.

Global — M-Lab NDT7 (Google-powered)

Uses the NDT7 protocol from Measurement Lab (M-Lab) — the same underlying tech behind Google's own "speed test" pop-up — deliberately independent infrastructure from Cloudflare, so a problem with one can't take down both tests. Picks the best server outside your own country automatically, falling back through a few candidates if one doesn't respond. Worth knowing: M-Lab is a public research platform and publishes collected results for internet research — see their privacy policy.
